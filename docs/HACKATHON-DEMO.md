# SBuddy 黑客松展示

## 打开

- 首页：http://localhost:3000/
- 独立展示空间：http://localhost:3000/?demo=1#play
- 人物动作对照：http://localhost:3000/animation-preview

网页端本地演示，不发布线上。保留当前依赖、环境与 3000 端口。已有依赖时，在 `site` 目录运行 `npm run dev`；已有服务正在运行时直接打开链接。

展示空间有独立的浏览器存储键 `sbuddy-showcase-v1`。个人空间仍用 `sbuddy-state-v2`。右上角“重置演示”恢复当天样例、清除展示进度，不清除个人记录或共享照片库；“退出”回到个人空间。跨日展示前点一次重置，让日期更新到当天。不要使用浏览器的“清除网站数据”来重置展示。

## 三分钟讲解

**0:00–0:25 · 介绍**

打开首页：“我们把日程管理、学习工具和像素角色陪伴放在同一张桌上，让完成计划也有情感反馈。”点击“体验展示”。说明这是预置样例空间；默契 48 和 12 以及小禾的两条学习习惯是展示样例，学习历史从零开始。

**0:25–0:55 · 陪伴与专注**

点击人物 → “聊聊” → 选择一个回答。展示底部对话；关闭后点击电子钟开始人物自习，同时展开右侧番茄钟，在这里开始一分钟专注。右侧工具默认隐藏：电子钟打开番茄钟，书本或电脑打开纪要。收起工具不丢失记录，也不会跳转到工具页。

**0:55–1:25 · 日程闭环**

点击左侧演示路线“把安排变成日程”。材料已经备好，点击“识别日程”，校对后“确认写入日历”。展示周/月视图、右侧待办与课程/考试页。重复导入会去重。番茄钟离开游戏页后继续。

**1:25–2:00 · 学习工具闭环**

回到游戏，点击桌面电脑 → 右侧纪要“整理重点” → 把一个行动项加入待办。上课时点击书本也能打开同一份纪要。无需离开场景即可速记与整理；完整版工具页仍可从导航进入。时间充裕时打开工具中的课件整理，展示提纲与 Markdown 导出。速记使用本地规则和原文摘录，界面注明来源。

**2:00–2:35 · 成长与角色隔离**

回到游戏页，查看专注结算和左侧新待办。专注自然完成后只记录真实的一分钟、奖励一次。鉴赏页查看解锁内容；角色页切到知序，说明外观、默契、对话各自独立，而学习资料属于用户。

**2:35–3:00 · 场景与收尾**

切换教室，角色离场后换景再返回；打开纯享模式，再用右上角入口或 Esc 退出。“学习不再只是勾掉任务，而是与一个记得你的搭子一起完成。”下一轮展示点“重置演示”。

## 备用演示

- 时间紧：先开始一分钟专注，再讲日历和纪要；不用等待录音或上传文件。
- 暂停演示离场：专注中点暂停，人物离开后保留空座；继续计时后返回。暂停时间不计入记录。
- 手机：展示空间仍可用；导航收进左上角菜单，日程与工具移到场景下方。
- 投影：浏览器保持 100% 缩放；建议 1280×720 或更宽，先打开首页与游戏页加载素材。
- 演示中修改样例后刷新，进度会保留。重置会中止当前展示计时并清除展示记录。

## 如实说明能力

已实现：两位默认序列帧人物、场景和桌面互动、角色独立对话/成长、日历/课程/考试/待办、真实专注计时、本地文本整理、备份恢复。

展示路径不依赖 AI 密钥。普通空间仍保留 AI 接口；未配置或失败时，文字整理使用明确标注的本地替代。展示空间的对话使用现有预设问题与回应。

照片生成接口及素材校验已接入，但真实照片生成、语音转写、截图识别需要有效服务，尚未验收真实生成一致性。实时听写取决于浏览器支持和权限；校园采集需要用户自行教务登录。手势需要摄像头，适合作为额外展示，不作为主线前置条件。首次加载或首次准备手势资源仍可能需要网络；不宣称完全离线安装。
