# 序列帧、桌面与日常活动调整

日期：2026-09-06。仅本地网页端，预览地址仍为 http://localhost:3000 。

## 本轮交付

- 男女默认人物各有 48 个完整姿势帧，替代默认人物的部件骨架。保留旧 V1/V2 自定义人物读取。
- 透明 PNG 原稿通过 imagegen 重新制作；未采用生成过程中出现的黑底、棋盘底版本。加载时只清理低透明度边缘，不按颜色删白，不伤眼白和衣领。
- 原稿采用经过检查的帧裁切窗口，注册到统一画布。待机、书写、招手、思考、庆祝、撑头、起坐、步行组成十种活动；上课组合听讲和记录，会议采用注视及点头。
- 活动通过放笔、收手和共同待机姿势连接；离场一旦开始便完成，空座保持到返回。场景只在离场后切换，普通动作不换背景。
- 桌面在逻辑画布 y=360 / 480 处开始，面积为下方 25%；使用平滑哑光表面，不再加载木纹桌面作为当前桌面。
- 保留人物点击、滑动的一小时间隔、独立默契、物件指令、自动庆祝、疲惫和番茄钟状态。
- 日常活动恢复左侧日历／课程表／考试、右侧待办，手机上下排列。完整周月视图、时间线、日期及时间选择、重复规则、提醒、编辑与待办撤销继续使用原共享状态。

## 素材与照片接口

`/api/ai/avatar` 保持不变，返回 `rigVersion: 3`、`imageUrl`、`spriteManifest` 和 `photoMode`。V3 清单定义六列八行、共同定位点、纸笔位置、动作索引、逐帧时长及循环标记。服务同时接收原人物照片和统一姿态参考；无人／多人照片拒绝生成，头像允许补身体。

客户端在替换前检查清单及每一格图像：尺寸、透明度、缺帧与跨格。原照片与图集一起保存并包含在备份中。导入损坏图集或不兼容清单时保留现有数据。旧 V1/V2 备份保持其素材版本，不强制转换。

真实服务未配置，因此本轮只验证接口模拟和模拟自定义外观的完整读写流程。真实照片的跨帧脸型、衣服、姿态一致性仍未验证；不会把接口模拟成功当作生成效果合格。

实际查看两位人物的待机、书写、招手和站起帧，检查连续播放与深浅底色。原先明显的白色外轮廓、旋转部件接缝已消除；桌面铺满下四分之一，人物和道具保持独立比例。笔画接触帧经重新定位，非持笔动作不显示额外悬空笔。
