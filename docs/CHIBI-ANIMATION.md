# Q 版场景、动画及素材契约

## 场景

- 游戏场景采用 480 单位高的逻辑画布，宽度跟随容器比例；背景独立 cover 裁切，人物不横向拉伸。桌面后沿 y=230，约为画面高度的 48%。
- 背景为 library / classroom，桌面单独绘制；纸张、拾笔点、座位和出口使用固定坐标。图书馆为默认场景，设置随完整备份保存。
- 绘制顺序：房间 → 身体和腿 → 桌面 → 纸笔 → 手臂与头。站立/行走时下半身由桌面遮挡。
- 切换房间先请求 away，人物到达画面外后切换已预载的背景，再接回当前活动。显式选择 away 时保持空座。减少动画设置使用静态姿态。

## 动作

chibi-rig.ts 定义十种活动、关键姿态、衔接段和共享约束。Canvas 每秒最多重绘 30 次；角色外观不参与动作计算。

- 自习：提笔、四组书写/抬笔回行循环、扶纸。上课：听讲与记录交替。会议：注视、点头和小幅手势。
- 招呼/庆祝：抬臂前先展开手臂，再屈肘竖起手掌；弯曲方向只在手臂伸展处改变。短动作播放完成后通知行为控制层，恢复当前指令；演示页可重复播放，游戏页由事件触发。
- 衔接：先把笔送回拾放点，降低手臂；起身、转向、步行和落座分段完成。快速切换在段落接点采用最新目标，不从头重置整个人物。
- 手臂采用两段 IK，手掌是独立素材，随腕部方向旋转；握笔手型与笔分开，笔随握持点移动。腿部使用固定长度约束，落脚期抵消身体前进距离。待机根节点不摆动。
- 头部使用正面、四分之三侧面、侧面及闭眼修形。角色卡片展示站立模型，游戏场景采用坐姿。

制作方法参考 [Spine IK 说明](https://us.esotericsoftware.com/spine-ik-constraints)及[可换装角色示例](https://eu.esotericsoftware.com/spine-examples-mix-and-match)，没有新增 Spine 或其他依赖。

## V2 外观

RigAppearance 新增可选 rigVersion: 1 | 2。已有 atlasKey 且没有版本时按 V1 读取；默认角色使用 V2。未知版本备份拒绝恢复，原素材保留。

V2 是 4×4 图集，接口请求 1536×1536 PNG，单格一个部件。顺序固定如下：

| 行 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 1 | 正面头 | 向左四分之三头 | 向左侧面头 | 同尺寸闭眼头 |
| 2 | 正面躯干 | 四分之三躯干 | 侧面躯干 | 腰胯/裙摆 |
| 3 | 左上臂 | 左前臂 | 右上臂 | 右前臂 |
| 4 | 张开手 | 握笔手（不含笔） | 大腿 | 小腿与鞋 |

躯干不含手臂，前臂不含手；所有衣袖端点朝下，上下连接点居中。运行时按透明内容裁切，头部使用下缘中心锚点，躯干和肢体使用上缘中心及重叠端点。方向、手型、闭眼等修形均来自图集。左右角色及上传外观共用坐标和时间线。

默认图集经内置图像工具生成及躯干修正。工具返回的默认图集带不透明棋盘底，因此默认加载器仅清除与单格外缘连通的浅中性色像素；封闭的衣服和眼睛高光保留。上传图集仍要求真实 alpha，不启用默认素材的底色处理，失败时不替换原角色。

照片接口保持 /api/ai/avatar，响应 rigVersion=2。识别人头或单人后生成完整外观，拒绝无人/多人/无效图集。头部补身保留 photoMode；旧图集、照片原件及版本信息均随备份恢复。

## 产出

public/scenes 包含 library-v2.png、classroom-v2.png、desk-v2.png；public/characters 包含男女 chibi-v2.png，旧 rig.png 原样保留。房间、桌面和人物位图通过内置 imagegen 生成；交互电子钟、书摞和电脑使用 Canvas 像素绘制。核心提示词要求：旧版 Q 版像素轮廓；男女不同头发与穿着；4×4 可换装部件；无人满幅图书馆/教室；独立满幅木桌面。

/animation-preview 提供十种活动、两种场景和旧版素材对照，不读写用户学习状态。scripts/verify-chibi.mjs 检查全部活动连接、落脚、短动作收尾、快速改选及备份版本；画面验收单独记录，程序测试不替代人工观感判断。


## 交互控制层（2026-09-06）

`companion-behavior.ts` 定义持久化 BuddyBehavior（mode、activity、lastInteractionAt）、日程时长区间合并、完成快照比较和目标动画优先级。`use-companion-behavior.ts` 管理短动作与合并庆祝；Provider 在页面间共享完成事件，恢复备份时重建比较基线。

- 优先级：暂停离场 → 招呼 → 提问思考 → 庆祝 → 日程/手动活动 → 普通或疲惫待机。换景由 Canvas 执行完整离场后切换；快速恢复专注仍先完成已经开始的离场。
- 以实际进入循环后的播放时长判定短动作完成，不用从点击起算的固定超时截断衔接。Canvas 回调包含动作与 token，旧回调不会结束新动作。
- 三个物件由现有 Canvas 原生像素绘制，几何锚点来自 DESK_OBJECTS：电子钟 (-92,291)、书本 (0,291)、电脑 (92,283)。DOM button 按同一逻辑坐标投影，支持键盘、触屏、选中态和加载/离场禁用状态。纸笔接触点未改变。
- 完成检测只观察既有未完成记录的变化及未修改日程跨过结束时间；暂停、删除、载入历史记录、隐藏页面期间的过期事件不补播。完成 ID 去重，事件不产生额外默契奖励。
- 持久化字段是可选扩展，旧备份默认 mode=schedule、fatigueHours=6、无互动时间。原素材 V1/V2、照片资源和解锁节点保持兼容；缓存版本为 v12。

专项测试覆盖一小时边界、指令切换、重叠时长、优先级、无上限默契、备份隔离及日程/待办/专注完成检测。浏览器结果见 VALIDATION.md。
