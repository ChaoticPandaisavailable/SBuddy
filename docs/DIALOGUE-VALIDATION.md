# 分步场景对话 · 2026-09-06

空闲和暂停休息时不渲染对话框。人物点击后，先单独展示开场文字；点击推进后只显示“聊聊 / 先忙”。正式对话同样依次展示问题、所有选项、回应，回应再点击即收起。关闭按钮始终独立可用。

问题与选项使用原生按钮，转换页面时将焦点移到可操作内容，支持 Enter/空格。每次推进仍刷新互动时间，人物独立记录与原有回答奖励规则不变；推进本身不奖励默契。

隔离来源浏览器 16 项检查通过：空闲无框、开场分步、焦点、取消无奖励、近期直接提问、不重置问题、问题选项分离、回应独立、关闭不重复奖励、手机宽度和完整选项、手机关闭、纯享无框和推进。

缓存版本 v16。临时验收页从公开目录移除，原文内容、选项及奖励未修改。

另实际使用 Enter 从问题推进到选项、空格选择回答、Enter 关闭回应；目视确认回应独占整框。规范、类型检查、110 项专项检查与正式构建通过。
