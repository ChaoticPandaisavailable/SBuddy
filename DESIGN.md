# SBuddy visual direction

Approved: warm campus, code-first, preserving the seven reference layouts.

Ivory #f8f6ef ground, paper #fffef9, ink #293a32, muted #68746b, moss #42664f, pale sage #e7ecdf, warm ochre #b47b3e. Clear 1px borders, 12–16px corners, no decorative gradients. Chinese serif for home display; readable Chinese sans for controls. Desktop header 76px, navigation 206px, content flexible. Main spacing 32px, controls minimum 40px. Mobile navigation drawer and stacked columns.

Home and play emphasize existing pixel companion artwork; daily activities emphasize calendar and persistent task rail. Game immersion hides app chrome. All controls have visible keyboard focus; reduced motion freezes character animation. Warm campus voice, concrete actions and honest empty states.
