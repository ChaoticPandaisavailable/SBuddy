# 完蛋！我被学习搭子包围了 / SBuddy

个人校园学习网页：日历、待办与专注记录共享，每位像素搭子独立保存外观、默契、对话、印象和成长奖励。当前交付为本地版本，无账号、云同步或公开部署。

## 黑客松展示

打开 [展示空间](http://localhost:3000/?demo=1#play)，使用预置日程、纪要、课件和一分钟专注完成演示。右上角可一键重置，个人空间数据与照片不受影响。展示文字整理使用本地规则并标注来源，无需 AI 密钥。

完整讲解顺序、备用路径与能力边界见 [三分钟演示指南](docs/HACKATHON-DEMO.md)。本次检查结果见 [展示验收记录](docs/HACKATHON-VALIDATION.md)。

## 本地运行

需要 Node.js 22.13 或更高版本。

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

打开终端显示的网址（默认 http://localhost:3000）。已有 .env.local 时不要覆盖它。首次启动会准备 MediaPipe 模型与 WASM，需网络下载；之后手势推理在浏览器运行。

```powershell
npm run lint
npm run test:campus
npm run test:sbuddy
npm run build
```

保留了原有 React、Vinext、Vite 和 Sites 配置。构建命令不发布网站。构建产物可用 npm start 本地预览（端口以 Wrangler 输出为准）。不同端口属于不同浏览器存储来源。

## 七页使用

- **主页**：固定宣传页，展示两位默认人物和进入按钮，不随当前角色、日期或学习记录变化。
- **开始游戏**：满幅像素房间与桌面，左侧日程待办、右侧番茄钟纪要、底部浅色透明对话框。左上角切换日程/手动指令并显示爱心默契，右上角切换场景与纯享模式。点击电子钟、书本纸笔、电脑分别进入自习、上课、会议；再次点击当前物件表示完成。点击人物开始对话。手机端把左右组件移到场景下方。
- **角色**：两位外观独立的默认人物：女生小禾与男生知序；可创建、命名并选择基础人物。旧版向阳保留在“旧版搭子”折叠栏，历史不合并、不删除。默契、对话、印象和照片外观按角色保存。“对我的印象”归纳对话偏好、可识别的学习习惯及最近一次专注反馈，不逐条复述答案；原始补充内容在“管理记忆”中保留并可删除，描述即时重算。当前归纳不需要 AI 服务，不会从不足的信息推断性格。
- **日常活动**：恢复左侧日历／课程表／考试、右侧待办的 SBuddy 布局，手机上下排列。保留周／月视图、当日时间线、年月选择、重复日程、提醒、完整编辑弹层，以及待办完成／恢复／撤销。日程识别继续在本页，不显示近期统计卡片。
- **工具**：课件整理、纪要、手势识别、番茄钟。课件整理支持粘贴文字、导入 PPTX/TXT/Markdown，生成概览、提纲与重点并导出 Markdown；配置 AI 后还可生成基于原文的自测问题。PPTX 按幻灯片顺序提取文字，图片、PDF 和旧版 PPT 需要先复制或识别文字；上限 10 MB、300 页、5 万字。无密钥或服务失败时明确显示“本地摘录提纲”。课件独立保存，不覆盖纪要或日程材料，并随备份恢复。切换页面保留编辑草稿与计时状态。番茄钟支持 10/25/45 分钟、自定义、暂停、继续、重置和结束；以时间戳计时，结算归属于开始时的搭子。结束后可以记录感受。
- **鉴赏**：默契 25/50/75 各解锁两项昵称、回应、动作或特别对话；回看不重复奖励。
- **设置**：音效、减少动画、默认专注时长、学期设置、备份恢复、演示数据与清空数据。新用户默认没有虚构学习记录。

## 日程识别与校园采集

日历左上角“日历设置”包含课程表、考试、导入、学期起始日、课表重置与“今日状态与启动建议”。压力、精力记录和 10 分钟启动入口保留；没有精力记录时显示“尚未记录”。课表重置按来源恢复最近保留的课表，并撤销对应课程的单次修改。

日程编辑包含活动/课程、标题、地点、开始与结束时间、提醒及重复。支持每天、每周、每两周、每月、每年，以及自定义间隔、星期、月内日期和倒数序号；不存在的日期不会移到下个月。可以设置结束重复日期。待办先选截止日期和时间，再按需添加多个提醒；完成后不再显示截止标记。提醒仅在网页运行期间显示，不具有手机应用退出后的系统通知能力。

组件功能对照本机 `D:/project/ruc-campus-assistant-workspace/app/apps/mobile/lib/features/calendar/`。可选“人大校历”采用该项目内置的校历快照，默认关闭，未重新核验学校后续调整；不会覆盖个人学期设置。月历、时间线、周课表、待办和编辑弹层保留完整功能，采用 SBuddy 的分栏布局与七页导航。参考项目和本项目 Flutter 代码没有修改。

入口统一在 **日常活动 → 日程识别**，日历页有直接入口，遵循“识别 → 编辑预览 → 确认写入 → 查看日历”。全程停留在日常活动内；旧书签 `#tools/schedule` 自动转到 `#daily/schedule`。切换其他页面保留尚未确认的预览，确认写入后返回日历。

文字日程根据实际参考日期解析今天、明天、下周等；不明确的日期和起止时间必须补全。重复确认相同安排会去重。文本文件与校园课表/考试的 HTML、TXT、JSON、CSV 和截图导入集中在此处。

校园采集复用原来的数智人大采集桥，只接受指定官方站点 jw.ruc.edu.cn。普通网页无法跨域读取登录后的教务内容：

1. 在“课表与考试 · 采集 / 文件 / 截图”中按说明复制采集代码、创建书签。
2. 从本站打开官方课表或考试页面，由用户自己登录。
3. 点击采集书签，将页面可见课表/考试表格回传预览；也可手动粘贴或上传文件。
4. 校对名称、周次/节次、日期、时间和地点，再确认写入。
5. 在设置中核对学期起始日，到日历查看结果。

不接收教务密码，不采集成绩。学校页面结构变化时可能需要调整解析器；真实登录采集需要用户在自己的浏览器完成。

## AI 与媒体

服务端现支持 **Aiping 千问文字/多模态 + Seedream 5 图片生成 + MOSS 语音转写**。复制 `.env.example` 为自己的 `.env.local` 并填写密钥，已有配置不要覆盖；修改后重启开发服务。密钥不进入前端或 Git。模型分工、接口参数、图片生成限制与测试步骤见 [API 接入说明](docs/ai-providers.md)。

文字日程、规则对话、默认搭子与文字摘录在无密钥时仍可使用，结果标注来源。MOSS 接入纪要里的上传录音与录音转写；浏览器实时听写仍使用浏览器能力。

照片生成经过单人识别、Seedream 六列八行动作图生成、透明背景处理和校验后才替换该搭子外观；失败保留原人物。V1/V2 旧素材仍兼容。

十种人物活动共享动作与衔接；持续活动无缝循环，招呼和庆祝结束后回到自然待机：打招呼、思考、庆祝、自习写字、上课记笔记、会议、疲惫、空闲、离场与返回。切换时放下物品、起身、走动、坐下，反复点击会接续到最新选择。身体不做整体摇摆或缩放；背景、桌椅保持固定，离场后人物停留在画面外。可在独立动作演示页检查所有动画，游戏页由日程、桌面物件及完成事件驱动。“减少动画”是用户主动选择的静态模式。

摄像头和麦克风只在主动点击后请求权限；离开对应工具会停止媒体流。录音可在当前会话下载；原始音频不会持久保存。转写文字与纪要会保存，可选择行动项加入待办。

## 数据、迁移与备份

- 结构化数据保存在当前来源的 localStorage（sbuddy-state-v2），照片素材保存在 IndexedDB（sbuddy-assets）。
- 所有学习数据属于用户；外观、关系与对话按稳定搭子 ID 隔离。异步对话、照片与专注结算按发起时的搭子写回。
- 第一次发现旧版单角色数据且没有新版数据时迁移到小禾；旧键原样保留。旧版无年份日程按原项目 2026 年背景迁移，新增日程不使用固定年月。旧个人资料原件也存档到新版数据的 legacyProfile。
- 导出备份包含全部角色、学习记录、草稿及照片；恢复先校验与预览，再由用户确认覆盖。恢复会替换当前结构化数据，建议先备份。
- 浏览器禁止存储、空间不足或数据损坏时页面明确提示。隐私浏览、清理浏览器数据、换浏览器或换端口可能造成记录不可见或丢失。
- 演示数据从设置手动载入并标示；不会在初始化时覆盖真实数据。
- 清空数据需要明确确认，包含旧数据和照片。关闭页面后的推送不在本地版本范围内。

## 满幅场景与 Q 版动画（2026-09-06）

开始游戏页默认使用像素图书馆，右上角可切换教室。房间铺满背景，桌面铺满下半幅；人物先离场，再切换房间并返回。普通活动不改变背景和桌子。左侧是当日日程与待办，右侧是纪要和番茄钟，底部是透明对话条。手机端把组件放在场景下方，纯享模式可用右上角按钮或 Esc 退出。

两位默认角色采用 Q 版比例：小禾是栗色短发与绿色开衫，知序是深色短发、眼镜与蓝色衬衫背心。自习时握笔写字、抬笔换行，另一只手扶纸；短招呼可以重复点击播放，离场后保持空座，点击“走回座位”返回。可展开“人物活动”手动查看十种活动。

[动作演示与旧版画风对照](http://localhost:3000/animation-preview)可同时查看男女角色。演示页不修改学习数据。[制作与素材契约](docs/CHIBI-ANIMATION.md)说明动作、V2 素材结构及兼容规则；本次实际验收见 [VALIDATION.md](VALIDATION.md)。照片生成人物的真实效果仍待配置图像服务后验证。

## 桌面互动与自动行为（2026-09-06）

- 默认按日程活动；点击桌面物件立即切换“等你出发”，不再跟随日程，直到主动切回。电子钟仅让人物自习，不启动番茄钟；点击其他物件只切换，再次点击当前物件才算完成。
- 首次点击人物或距上次互动至少一小时，招手并询问“Hello，想聊聊吗？”，可选“聊聊 / 先忙”。一小时内直接对话；人物点击、回答及收起对话都会刷新计时，按角色保存，刷新继续有效。不会到点主动弹窗。
- 人物提问时思考，回答后的回应不庆祝。默契继续按原对话和专注规则积累，没有 100 上限；原有 25/50/75 奖励仍有效。
- 日程自然结束、待办勾选、手动活动完成及专注结算会庆祝一次，同时完成合并播放。历史导入、刷新、编辑或删除日程不补播；对话期间庆祝等到问题结束后再播放。
- 暂停番茄钟会离场保持空座，继续后回座；换场景也先离场再换背景。暂停期间换景后仍保持空座，离场和返回期间不能点击桌面物件。
- 当天学习、课程和会议安排合计达到 6 小时，自然待机时撑头休息；重叠时间合并，次日重新计算。“设置 → 人物状态”可调整阈值。活动和对话不被疲惫覆盖。
- 互动计时、指令和活动按搭子保存，疲惫阈值随完整备份恢复；旧备份缺少这些字段时自动补默认值。人物素材格式和照片接口不变。

## 游戏手势与照片静态外观

“开始游戏”右上角 → “手势互动” → “开启摄像头”。张开手掌打开对话，比 V 开始 10 分钟专注，握拳暂停/继续，拇指向上结束本轮，拇指向下暂停休息。已有其他搭子的专注不会被误操作。关闭面板、离开游戏或切换搭子会停止摄像头；视频仅在本机识别，不录音。权限拒绝或设备失败会显示原因，可继续用鼠标和键盘。纯享模式也可使用该入口。

照片换肤先生成一个静态人物，预览后应用，也可下载。静态人物仍支持对话、专注与手势，但暂不播放行走、挥手等动作。未应用的预览在离开角色页或刷新后不保留。运行 `npm run test:portrait` 与 `npm run test:gestures` 验证本次改动；服务配置及实测范围见 [AI 接入说明](docs/ai-providers.md)。
